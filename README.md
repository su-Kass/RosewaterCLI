## Rosewater
Rosewater is just a wrapper for Roblox and Rosemary!
It directly runs the Roblox MacOS client under Rosemary, allowing you to 
play Roblox on Linux on a computer-scoped executable!

RosewaterCLI Handles Rosemary/Roblox updates automatically

## Rosewater is still being developed!
You can always compile RosewaterCLI from source until an appimage, flatpak, or other is available for
you to use!

## Notice:
RosewaterCLI does not package Roblox, or Rosemary, it downloads Rosemary from github, and it downloads
Roblox from their official CDN URL; No external code is packaged

## Requirements
go (if you are building)

## System support:
Currently tested on CachyOS, does not have directory settings yet
but configuration through the interactive CLI is planned!

## How to use RosewaterCLI
RosewaterCLI currently does not have compiled binaries
That means you have to compile it yourself!

You can do that by downloading the source code (or cloning the repo)
And then doing `go build -o RosewaterCLI` Which will compile it

Afterwards you can do `chmod +x RosewaterCLI` (or just make it executable from your explorer)
you then have two options, RosewaterCLI is meant to be run directly from your terminal.

You can do this with `./RosewaterCLI`
You can also ATTEMPT to just double click it, however it sucks and isnt the correct way to
start this program, please wait for Rosewater (if I make it ofc)
