## How to use RosewaterCLI
RosewaterCLI currently does not have compiled binaries
That means you have to compile it yourself!

You can do that by downloading the source code (or cloning the repo)
And then doing `go build -o RosewaterCLI` Which will compile it

Afterwards you can do `chmod +x RosewaterCLI` (or just make it executable from your explorer)
you then have two options, RosewaterCLI is meant to be run directly from your terminal.

You can do this with `./RosewaterCLI`
You can also ATTEMPT to just double click it, however it sucks and isnt the correct way to
start this program, please wait for Rosewater (if I make it ofc)
